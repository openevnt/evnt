# Libraries

A list of programming libraries and SDKs for working with Open Evnt.

If this list is incomplete, please open an issue or make a pull request.

## Official TypeScript Libraries

Along with the specification, the Open Evnt project maintains a set of official TypeScript libraries.

- [@evnt/types](https://npmx.dev/package/@evnt/types) - TypeScript types for Open Evnt events.
- [@evnt/schema](https://npmx.dev/package/@evnt/schema) - Zod schema for validating Open Evnt events.
- [@evnt/pretty](https://npmx.dev/package/@evnt/pretty) - Pretty-printing for Open Evnt events.
- [@evnt/partial-date](https://npmx.dev/package/@evnt/partial-date) - Utilities for working with Open Evnt partial dates.
- [@evnt/translations](https://npmx.dev/package/@evnt/translations) - Utilities for working with Open Evnt translations.
- [@evnt/convert](https://npmx.dev/package/@evnt/convert) - Conversion utilities between Open Evnt and other event formats.
