# Applications

This page lists the services, applications, and tools that support Open Evnt.

To add an entry to this page, open an issue or a pull request.

- [eventsl.ink](https://eventsl.ink) - A tool that makes shareable links to Open Evnt events.
- [Vantage](https://vantage.tsx.lt) - A calendar application with Open Evnt support.
